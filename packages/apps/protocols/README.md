# Host protocol records

Generated by `scripts/check-app-protocols.ts`; do not edit by hand.

Each `<N>.json` records host protocol N: every message that crosses between an
Executor host and an app bundle built with a framework that speaks protocol N,
as Effect's representation of the message's JSON form. A record lists only the
messages that differ from protocol N-1 and names the rest in `unchanged`.

Released protocols are frozen in `../src/contracts/protocols/<N>.ts` and must
keep recording exactly as their file says. The protocol the framework speaks is
`../src/contracts/protocols/current.ts`; its record is re-recorded with
`bun run apps:protocols --write`, which refuses a change that would stop the
host from running the bundles of any released protocol.

`gates.json` lists the differences the host may send a released protocol's
bundles only when they declared support, and the messages a host adapter
converts. See `notes/apps-publishing.md` in the private repository for the
rules.
