# Security

If you find a security problem in Executor, please tell us privately. Either
channel is fine:

- Email [security@executor.sh](mailto:security@executor.sh).
- Open a private report through
  [GitHub private vulnerability reporting](https://github.com/UsefulSoftwareCo/executor/security/advisories/new).

Please do not open a public issue or pull request for a vulnerability.

Include what you can of:

- The affected version or commit.
- Where it runs: hosted Executor at executor.sh, a self-hosted install, or
  local Executor.
- Steps to reproduce.
- The impact: what an attacker can do, and what they need first.

We do not run a bug bounty.
